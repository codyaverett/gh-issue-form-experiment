Features

  • Dynamic dropdowns populated with live GitHub data (branches, releases, tags)
  • Conditional fields that change based on previous selections
  • Label selection with color swatches from your repository
  • Seamless integration with GitHub Issue Forms via pre-filled URLs
  • No server required - runs entirely on GitHub Pages
  • Caching to minimize API calls and respect rate limits
  • Optional token authentication for higher rate limits

How It Works

  1. User submits Stage 1 via native GitHub Issue Form
  2. Workflow posts a link to this dynamic form with URL parameters
  3. Dynamic form fetches live data from GitHub API
  4. User fills form; conditional fields update based on selections
  5. Form generates a pre-filled GitHub Issue URL for Stage 3
  6. Process continues through the multi-stage wizard
